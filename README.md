# ПДД-тренажёр

Локальный тренажёр теории ПДД для **России** и **Беларуси**: билеты, темы, экзамен, разбор ошибок, справочник знаков и разметки.

## Запуск

**Основной тренажёр и симулятор** — один статический сервер:

```bash
npm start
# → http://127.0.0.1:8000/              билеты, экзамен, справочник
# → http://127.0.0.1:8000/index.sim.html  2D-симулятор RoadMind
```

> **Важно:** `npm run dev` (Vite, порт **5173**) — отдельный React-прототип (`index.vite.html`), это **не** основной тренажёр. Для билетов и симулятора используйте `npm start`.

Симулятор: сценарии + **поездка по городу** (WASD). Знаки — **ГОСТ SVG** (Wikimedia) + CC0-машины, см. [assets/ASSETS.md](assets/ASSETS.md).

```bash
npm run fetch-assets   # скачать ГОСТ SVG + машины с Wikimedia / OpenGameArt
```

## Разделы

- **Билеты** — 20 вопросов с навигацией как на экзамене: можно пропускать, вернуться к неотвеченным, флажки
- **Темы** — линейная тренировка по разделам ПДД с подсказками после ответа
- **Экзамен** — таймер, правила ГИБДД (РФ) / экзамена (РБ); во время экзамена не показывается, верно ли ответ — разбор только при неудаче
- **Разбор ошибок** — вопросы с ошибками из билетов и экзамена; чем чаще ошибка, тем выше шанс попасть в сессию
- **Справочник** — полный текст ПДД (26 глав), знаки 1–8 и разметка с [avto-russia.ru](https://avto-russia.ru/pdd/)
- **Статистика** — прогресс по темам, история экзаменов, очередь разбора
- **Настройки** — тема, шрифт, импорт банка и прогресса

## Банки вопросов

Данные в `data/`:

| Файл | Описание |
|------|----------|
| `pdd-ru-ab.json` | Россия, категории A/B |
| `pdd-ru-cd.json` | Россия, категории C/D |
| `pdd-by-ab.json` | Беларусь |

Сборка банков:

```bash
node scripts/build-pdd-banks.mjs      # Россия
node scripts/scrape-pdd-by.mjs        # Беларусь
node scripts/scrape-pdd-by.mjs --retry
```

Справочник знаков и разметки:

```bash
npm run scrape-ref
# → data/pdd-ref/index.json + data/pdd-ref/img/*.png

npm run scrape-rules
# → data/pdd-ref/rules/ — полный текст ПДД по 26 главам

npm run scrape-all   # знаки + разметка + ПДД
```

## Стек

Vanilla HTML + CSS + `app.js`. Без сборки, без npm.

Код симулятора (`citygen.js`, `drive.js`, `roadmind.js`, `scenarios/`) оставлен для будущей разработки — см. [ROADMAP.md](ROADMAP.md) и [assets/ASSETS.md](assets/ASSETS.md).

```bash
npm run fetch-assets   # скачать ГОСТ-знаки + CC0-машины
```

ГОСТ-знаки в **SVG** лежат в `assets/svg/gost/` (источник — [Wikimedia Commons](https://commons.wikimedia.org/), скрипт `fetch-assets.mjs`). В справочнике для знаков сначала показывается SVG, иначе PNG с avto-russia.ru. В симе Pixi грузит те же SVG.

## Горячие клавиши в квизе

`1`–`4` или `A`–`D` — выбор ответа · `Enter` / `N` — следующий вопрос / вперёд
