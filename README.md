# МедТренажёр — учим названия лекарств и товаров аптеки

Веб-тренажёр (vanilla HTML/CSS/JS, без сборки и фреймворков) для заучивания названий
препаратов, БАД и аптечных товаров по фото упаковки. Данные и фотографии — с
каталога [apteka.by](https://apteka.by/) (интернет-аптека, Беларусь).

> Разработка ПДД-тренажёра (билеты, экзамен, разбор ошибок, справочник ПДД, 2D-симулятор)
> вынесена в отдельную ветку [`pdd-trainer`](../../tree/pdd-trainer) — здесь, в `main`,
> с нуля собирается новый проект.

## Быстрый старт

```bash
npm run scrape   # один раз — тянет названия/фото/категории с apteka.by в data/meds/
npm start        # локальный сервер на http://127.0.0.1:8000
```

Открой `http://127.0.0.1:8000/index.html`.

## Категории

Структура повторяет разделы каталога аптеки (как на скрине с сайта):

| Категория | Источник на apteka.by |
|---|---|
| Лекарства от А до Я | `/drugs` (только твёрдые формы — таблетки/капсулы) |
| БАД от А до Я | `/bads` (только твёрдые формы) |
| ИМН от А до Я | `/medicinskie-izdeliya` |
| Лечебное питание | найдено по ключевым брендам (Nutridrink, Peptamen, Fresubin…) среди лекарств/БАД |
| Тонометры | `/medicinskaya-tehnika/tonometry-i-prinadlezhnosti-*` |
| Глюкометры | `/medicinskaya-tehnika/glyukometry-i-prinadlezhnosti-*` |
| Тест-полоски | `/medicinskie-izdeliya/.../testy-diagnosticheskiye-*` |
| Тесты на беременность | `/medicinskie-izdeliya/.../testy-na-beremennost-i-ovulyatsiyu-*` |
| Контактные линзы | `/optika/kontaktnyye-linzy-*` |
| Аптечки | `/medicinskie-izdeliya/aptechki-i-tabletnitsy-*` |

На момент последнего запуска `npm run scrape` собрано **~1000 товаров** с фото.
«Лечебное питание» — самая тонкая категория (2 товара): в общем каталоге аптеки
клинического энтерального питания почти нет, это ограничение источника, а не скрипта.

**Важно про фото:** apteka.by показывает фото *упаковки* (коробка/блистер), а не голой
таблетки без коробки — сайтов с фотографиями именно россыпи таблеток по каждому
бренду в открытом доступе для Беларуси не нашлось. Чтобы всё равно тренировать
узнавание "по внешнему виду, а не по надписи", в тренажёре есть **размытие названия
на фото** (см. ниже) — так или иначе учишься по форме/цвету/расположению элементов
упаковки, а не читаешь готовый ответ.

## Типы заданий

1. **Выбор названия** — по фото выбираешь верное название из 4 вариантов.
2. **Найди упаковку** — обратный вариант: дано название, ищешь фото среди 4-х.
3. **Введи название** — печатаешь название сам (без подсказок-вариантов), проверка с
   допуском на опечатки.
4. **Сопоставление** — соединяешь 6 фото с 6 названиями кликами (раунды по 6 пар).
5. **Определи категорию** — по фото/названию выбираешь категорию товара (нужно ≥2
   выбранных категории в сессии).
6. **Карточки** — классические флеш-карты: смотришь на фото, вспоминаешь название,
   сам себя оцениваешь «знал / не знал».

Во всех режимах можно включить **«Скрывать название на фото»** — упаковка
показывается размытой (форма/цвет видны, текст — нет), с кнопкой-глазом
«подсмотреть», удерживая которую можно на секунду увидеть чёткое фото. После ответа
фото всегда открывается чётко для запоминания.

Есть и адаптивное повторение: включённая по умолчанию опция «чаще показывать то, в
чём чаще ошибаюсь» взвешивает выбор вопросов по личной статистике ошибок
(хранится в `localStorage`), а после каждой сессии можно нажать «Повторить ошибки».

## Структура проекта

```
index.html            разметка (главная / квиз / результаты / статистика)
styles.css            стили
app.js                вся логика тренажёра
scripts/
  scrape-apteka.mjs   скрапер apteka.by → data/meds/*.json + data/meds/img/**
data/meds/
  index.json          сводный список категорий (для главного экрана)
  <category>.json     товары категории: { id, name, manufacturer, image, sourceUrl }
  img/<category>/…    фото упаковок (webp/jpg)
```

Повторный запуск `npm run scrape` докачивает только новые фото (уже скачанные не
трогает) и переписывает JSON. Можно ограничить категории: `node scripts/scrape-apteka.mjs --only=lekarstva,bad`.

## Данные и лицензия

Названия, фото упаковок и производители — справочные данные каталога apteka.by,
используются только для личного заучивания названий (обучающий тренажёр), без
цен, заказа и коммерческого использования.
